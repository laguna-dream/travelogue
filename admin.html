Run locally

Open this file via your local server: python3 -m http.server 8000 → localhost:8000/admin.html

Dispatch

  • Drop a .md or .txt file to auto-fill the body field
  • The ID field is important — it's what the map uses to link popups back to posts. Use something like day-1 or triund-hike
  • The place field must match a key in data/config.json → places (e.g. dharamkot, bir)
  • Reference a map pin inline with {{shiva-cafe}} — it renders as a small clickable chip

Map pin

  • The ID is what you use in {{double-braces}} in dispatch bodies
  • Get coords: right-click anywhere in Google Maps → first number is lat, second is lng
  • Setting dispatchId adds a "read post →" link in the map popup
  • For trails, set type to trail — you can add trailCoords manually as a lat/lng array after generating
  • Set inPath: true on places to connect them with a dashed route line

Sensory entry

  • Drop an image to get a preview and auto-fill the file path
  • The place field ties this entry to the map — sensory pins appear near that area's coordinates
  • After generating, move your file to: assets/images/ (images) or assets/sounds/ (audio)
  • Image entries show as photo thumbnails on the map — clicking them opens the slideshow

Adding entries to JSON files

Copy the generated JSON object and paste it at the top of the array in the relevant data file (newest first). Make sure to add a comma after your new entry. Then save, git add . && git commit -m "...", push.

Working Copy (mobile)

Install Working Copy on iPhone, connect to your GitHub repo. You can edit any JSON file directly from your phone and commit — site updates automatically.
